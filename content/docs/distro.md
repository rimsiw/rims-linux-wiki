## Beginner-Friendly Distros

- ⭐ **[Linux Mint](https://linuxmint.com/)** - Beginner friendly distribution based on Ubuntu | {{< ico simple debian 1.5em >}}
- [Pop!_OS](https://pop.system76.com/) - Secure and reliable distribution | {{< ico simple debian 1.5em >}}
- [elementaryOS](https://elementary.io/) - Distro based on Ubuntu with Pantheon desktop environment | {{< ico simple debian 1.5em >}}
- [Linux Lite](https://www.linuxliteos.com/) - Lightweight distribution | {{< ico simple debian 1.5em >}}
- [Solus](https://getsol.us/) - Distribution made from scratch, using eopkg package manager | {{< ico bootstrap patch-question 1.3em >}}

## Intermediate Distros

- ⭐ **[Debian](https://www.debian.org/)** - Independent Linux distribution | {{< ico simple debian 1.5em >}}
- ⭐ **[Fedora](https://fedoraproject.org/)** - Popular desktop distribution | {{< ico simple fedora 1.5em >}}
- ⭐ **[openSUSE](https://www.opensuse.org/)** - Easy to learn distribution | {{< ico bootstrap patch-question 1.3em >}}
- ⭐ **[EndeavourOS](https://endeavouros.com/)** - Arch-based user-friendly Linux distribution | {{< ico simple archlinux 1.5em >}}
- ⭐ **[CachyOS](https://cachyos.org/)** - Fast arch-based distro for gaming and day to day use | {{< ico simple archlinux 1.5em >}}
- [Damn Small Linux](https://www.damnsmalllinux.org/) - Extremely lightweight Linux distribution | {{< ico simple debian 1.5em >}}
- [ArchCraft](https://archcraft.io/) - Lightweight arch Linux fork with pre-riced window manager | {{< ico simple archlinux 1.5em >}}
- [Nobara](https://nobaraproject.org/) - "Gaming" distro based on Fedora | {{< ico simple fedora 1.5em >}}
