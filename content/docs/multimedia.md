## Media Player

- ⭐ **[mpv](https://mpv.io/)** - Cross-platform movie player | {{< ico lucide terminal 1.5em>}}
- ⭐ **[Haruna](https://haruna.kde.org/)** - Qt frontend for mpv
- ⭐ **[Kodi](https://kodi.tv/)** - Entertainment center
- [Celluloid](https://celluloid-player.github.io/) - GTK frontend for mpv
- [kawaii-player](https://github.com/kanishka-linux/kawaii-player) - mpv frontend with PC-to-PC casting functionality
- [vlc](https://github.com/videolan/vlc) - Cross-platform open source media player and multimedia engine
- [Glide](https://github.com/philn/glide) - Media player based on GStreamer
- [Stremio](https://www.stremio.com/) - Torrent based entertainment experience
